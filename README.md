# Buddies Pizza Landing Page

Basically, I want a landing page for a pizza website named Buddies Pizza.  I have attached my mood board where you can see the inspiration design. The prices should be in Pakistani rupees, and I have also attached the actual pizza menu.  I want you to design a landing page where there is a CTA button for the frontend (it doesn't have to be functional right now) and a booking option.  Please do not use any kind of AI slop or purple gradient type things. 

I want textures and grains overall on our website so it feels more alive with more elements. 

Please use real pizza images from the internet or created by yourself, but they should look real. Now I have a test image; build accordingly.The first image is the reference image, and the second image is the actual menu of the restaurant.

Please extract everything from the menu, and recreate the design of the menu according to the first reference image I added.

Make sure to note that the restaurant doesn't have dine-in dining now; they are totally dependent on delivery and takeaway. Please design accordingly.
